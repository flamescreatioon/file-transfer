# Changelog

All notable changes to AirBridge are documented in this file.

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The canonical release version is stored in [`VERSION`](VERSION).

## [1.0.0] - 2026-10-02

### Added

- Desktop C++ application with a local browser dashboard.
- Flutter Android client for LAN file and clipboard sharing.
- UDP peer discovery and manual IP connection.
- File-transfer progress, duplicate-name handling, and Android inbound-transfer confirmation.
